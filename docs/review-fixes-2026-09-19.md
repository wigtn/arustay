# 품질 리뷰 후 수정 · 2026-09-19

## 반영한 변경

### 소개 사진

- 내장 브라우저의 새 탭에서도 사진의 지연 로딩이 시작되지 않는 현상을 재현했다.
- 사진을 `loading="eager"`, `fetchPriority="low"`로 요청하도록 변경했다. 메인 사진의 우선 로딩은 유지했다.
- 실제 표시 폭에 맞게 `sizes`를 조정했다. 320px 화면에서는 280px, 데스크톱에서는 최대 420px다.
- 페이드는 사진 영역에만 적용한다. 설명 캡션은 처음부터 불투명하게 표시한다.
- 수정 후 동일 브라우저에서 사진 로딩 완료와 실제 이미지 표시를 확인했다. 브라우저 내부에서 지연 로딩이 멈췄던 원인까지 확정한 것은 아니다.

### 첫 화면

- 문구 전체에 적용하던 1.6초 이동·불투명도 효과를 제거했다. 제목·설명·링크는 처음부터 제자리에 선명하게 표시된다.
- 사진은 로딩 완료 후 2.2초 동안 1.045배에서 원래 크기로 돌아온다. 문구와 사진의 별도 시작 시계 문제를 없앴다.
- 기존 사진 네 곳의 스크롤 진입 페이드와 움직임 줄이기 설정을 유지했다.
- 모바일 설명문의 대비는 현재 색상에서 약 8.29:1이다. 불투명도 때문에 약 0.48초간 대비가 떨어지던 구간을 없앴다.

### 글꼴과 검사 도구

- 관리자 Inter 글꼴의 preload를 껐다. 공개 페이지의 폰트 preload 목록에는 라틴 제목 글꼴 두 개만 남는다.
- 폰트 preload 파일 크기 합계: **95,420 B → 46,988 B**, 48,432 B 감소. 페이지 전체 전송량이나 LCP 개선 수치가 아니다.
- `npm run lint`를 ESLint CLI로 변경하고 Next.js Core Web Vitals flat config를 추가했다. 규칙을 끄거나 기존 파일을 검사 대상에서 제외하지 않았다.
- 새 검사에서 드러난 기존 LegalModal의 effect 내 동기 상태 변경·내부 링크와 RoomCarousel의 렌더 중 ref 쓰기를 수정했다. 모달은 열릴 때 상태를 초기화하고 닫히면 내용을 해제하며, 기존 body overflow 값을 복원한다.

### 객실 갤러리

- 수평 이동이 45px를 넘고 세로 이동의 1.25배보다 클 때만 사진을 전환한다.
- 세로 스크롤이나 드래그 직후 확대 클릭이 발생하지 않게 처리했다.
- 시작한 손가락 ID를 확인하고, 다중 터치·취소된 제스처는 전환에서 제외한다.
- 브라우저의 세로 스크롤과 핀치 확대를 허용한다. 키보드로 확대하는 동작도 유지한다.
