# ARU STAY 리뉴얼 1차 구현

## 시각 디자인 보완

- 헤더는 글자로 대체했던 브랜드명을 기존 심볼·워드마크 원본으로 교체했습니다. 언어 선택은 기본 선택 상자로 묶고 메뉴와 예약 버튼 간격을 넓혔습니다. 높이는 모바일 80px, 데스크톱 88px이며 본문 시작 위치와 앵커 이동 여백에 동일한 값을 적용합니다.
- 제목은 짧은 안내형 문구를 사용합니다. 장식적인 쉼표·문장 끝 마침표·고정 줄바꿈을 없애고, 화면 폭에 따라 균형 있게 줄을 나눕니다. 본문 문장의 정상적인 문장부호는 유지합니다.

- 프로토타입의 메인 사진 원본을 확보해 첫 화면과 공유 이미지에 적용했습니다. 출처는 `public/images/PROVENANCE.md`에 기록했습니다.
- 제목에는 Gmarket Sans에서 만든 WOFF2 서브셋을, 본문과 조작 요소에는 시스템 산세리프를 사용합니다. 기존 갈색·크림 팔레트를 유지하고 사진, 글자, 예약 혜택 패널의 순서를 명확히 합니다. 메인 사진 위의 겹침은 혜택 패널 한 곳으로 제한합니다.
- 큰 제목을 반복하지 않도록 크기와 섹션 여백을 조정했습니다. 약한 테두리·텍스트 링크를 사용하고 큰 둥근 카드, 반복된 장식 아이콘과 그림자를 줄였습니다.
- 기능 아이콘은 동일한 선 두께로 맞추고, 사진 준비 중 화면은 기존 실제 브랜드 로고를 사용합니다.
- 사진이 전혀 없는 지점의 객실은 간단한 링크 목록을 사용합니다. 사진이 들어오면 같은 데이터에서 사진 카드로 바뀝니다. 후기 영역은 갈색 배경과 예시 카드 3개로 구성하고, 카드마다 실제 후기가 아닌 미리보기용 예시임을 표시합니다.
- 버튼·링크의 키보드 포커스, 44px 이상 주요 조작 영역, 움직임 줄이기 설정을 유지합니다. 확대·화살표 효과는 짧고 작게 제한합니다.

## 화면

- 메인: `/` (영어), `/ko`, `/ja`, `/zh`
- 지점: `/locations/wangsimni`, `/locations/dongdaemun`
- 객실: `/locations/{지점}/rooms/{객실}`
- 안내: `/policies`, `/privacy`, `/terms`
- 영어 외에는 같은 경로 앞에 언어 코드를 붙입니다. 언어를 바꿔도 지점·객실 경로를 유지합니다.

메인 → 지점 비교 → 지점 상세 → 객실 상세 흐름으로 구성했습니다. 공통 예약 버튼은 지점 선택 팝업을 열고, 지점·객실 화면에서는 해당 지점의 예약 버튼을 보여줍니다. Long Stay와 OTA·Google Form 예약 링크는 새 공개 화면에서 사용하지 않습니다.

## 콘텐츠를 교체하는 위치

| 항목 | 파일 |
| --- | --- |
| 지점 주소, 지도, 사진, 예약 링크, 객실 목록·사양 | `lib/stays.ts` |

지점을 추가할 때는 `stays` 배열에 같은 구조의 데이터를 추가합니다. 페이지, 객실 목록, 지점 선택, 사이트맵은 이 배열을 사용합니다. 리뉴얼 데이터는 파일 기반이며 기존 관리자 CMS와의 새 연동은 이번 범위에 포함하지 않았습니다.

## 현재 준비 중인 항목

- 두 지점의 `bookingUrl`은 `null`입니다. 버튼을 누르면 준비 중 안내와 이메일 문의가 표시됩니다. 실제 HTTPS 예약 URL을 입력하면 해당 지점으로 이동합니다. 날짜 선택·결제 기능은 외부 예약 서비스에서 처리합니다.
- 동대문 주소·지도·사진·객실 사양, 왕십리 디럭스 더블 사진·일부 사양은 준비 중 표시를 사용합니다.
- 소개 문구, 이용 정책, 개인정보 처리방침, 이용약관은 검토용 초안입니다. 후기 카드는 실제 투숙객 후기가 아닌 예시 문구이며 4개 언어 모두 예시 표시가 있습니다. 확인된 후기를 전달받으면 문구와 출처를 함께 교체합니다.
- `draft: true`인 지점·객실과 정책 초안은 `noindex` 처리하고 사이트맵에서 제외했습니다. 확정된 정보로 교체한 뒤 해당 상태를 변경합니다. 정책 페이지는 별도의 명시적 검토 후 색인 여부를 변경합니다.
- 동대문에 왕십리 주소·지도·숙소 구조화 데이터를 복제하지 않았습니다. 사진이 없는 페이지의 검색 공유 이미지는 브랜드 아이콘을 사용합니다.

## 확인한 기본 동작

- 예약 팝업의 Tab / Shift+Tab 순환, Escape·닫기 버튼, 선택 화면 전환 후 포커스, 닫은 뒤 원래 버튼으로 복귀
- 객실 페이지의 4개 언어 전환과 같은 객실 URL 유지, 모바일 메뉴에서 언어 변경
- 갤러리 사진 이동·확대, FAQ 열기·닫기
- 320~1440px 주요 화면 폭, 320px에서 4개 언어 메인·지점·객실 가로 넘침
- 모바일 하단 고정 버튼 위로 푸터의 마지막 내용이 보이는 여백
- 지점·객실별 제목·canonical·언어별 주소, 동대문 준비 중 페이지의 noindex

타입 검사와 프로덕션 빌드가 통과했습니다. 최종 빌드를 로컬 서버에서 실행해 48개 다국어 페이지의 HTTP 응답·제목·H1·canonical·언어별 검색 주소를 확인했고, 잘못된 주소 3개의 404와 초안의 사이트맵 제외도 확인했습니다. 실제 예약 완료 흐름은 예약 URL을 받은 뒤 검증해야 합니다.

## 로컬 실행

```sh
npm run dev -- --hostname localhost --port 3100
```

`http://localhost:3100/`에서 기본 영어 화면을, `/ko`에서 한국어 화면을 봅니다. 브라우저 언어 감지에 따른 자동 전환은 사용하지 않습니다. 검증 시 `localhost` 호스트로 실행했습니다. 관리자 화면은 기존 Google Inter 폰트를 사용하므로 최초 프로덕션 빌드에는 해당 폰트를 가져올 네트워크 연결이 필요합니다. 공개 페이지의 제목은 저장소에 포함한 Gmarket Sans, 본문은 시스템 서체를 사용합니다.

## 2026-09-18 언어·배포 점검

- 영어 기본값과 언어 자동 감지 비활성화를 재확인했습니다. 한국어·일본어·중국어 요청 헤더 및 언어 쿠키가 있어도 `/`는 영어로 열립니다. `/en/...`은 같은 영어 경로의 접두사 없는 주소로 이동합니다.
- 4개 언어의 공개 화면 문구를 대조했습니다. 일본어 지점 예약 버튼의 어순, 중국어 소개·후기 표현, 체크아웃 정오 표기, 공식 홈페이지 예약 혜택의 조건, 체크인 전·체크아웃 후 짐 보관 안내를 정리했습니다. 객실 정원·에어컨·평면 TV 표기도 언어 간 의미를 맞췄습니다.

- 브라우저에서 영어 → 일본어 → 중국어 → 한국어 → 영어 전환 시 왕십리 더블룸 경로 유지, 일본어 예약 팝업의 Escape 닫기·원래 버튼으로 포커스 복귀를 확인했습니다. 320px·390px에서 4개 언어 메인과 일본어 객실 페이지의 가로 넘침을 확인했으며, 사진 썸네일은 의도된 가로 스크롤 영역입니다.

## 2026-09-18 디자인 비교 후 보완

- 소개에서 반복되던 가치 설명 3개를 덜고, 짧은 운영자 시점의 소개와 인사로 정리했습니다. 사진 한 곳에 로고의 아치 형태를 적용하고 사진 설명을 4개 언어로 추가했습니다.
- 후기의 갈색 배경을 복원하고 3열 예시 카드를 배치했습니다. 모바일에서는 세로 목록으로 전환합니다. 가상의 이름·국적·평점은 넣지 않았습니다.
- 지점 소개의 상세 링크와 예약 버튼을 구분했습니다. 마지막 예약 영역은 밝은 모래색, 푸터는 진한 갈색으로 나눴습니다.
- 제목과 본문의 서체 역할을 구분하고 소개 본문을 17~18px, 충분한 줄 간격으로 조정했습니다. 아치는 소개 사진에만 사용하며 다른 사진·카드에는 반복하지 않습니다. 얇은 구분선, 기존 포커스 표시, 움직임 줄이기 설정을 유지합니다.
- 프로덕션 빌드·타입 검사·공백 검사가 통과했습니다. 브라우저에서 4개 언어 × 6개 화면 폭(320/390/768/1024/1280/1440px)의 제목·버튼 넘침과 헤더 겹침을 확인했습니다. 왕십리 지점과 일본어 더블룸도 320/1280px에서 공통 스타일을 확인했습니다.
- 모바일 운영자 사진의 로딩·얼굴 크롭, 왕십리 지점 예약 버튼, 동대문 하단 예약 버튼, Escape 닫기와 원래 버튼으로 포커스 복귀, 하단 고정 버튼 위의 푸터 여백을 확인했습니다. 실제 예약 완료는 여전히 예약 URL 입력 후 검증 대상입니다.

## 2026-09-18 배포 전 마감

- 제목용 글꼴을 라틴 문자·한글 및 두 굵기의 WOFF2로 나눴습니다. 기존 TTF 2개 합계 4,928,996바이트에서 전체 WOFF2 합계 1,002,984바이트로 약 80% 줄었습니다. 미리 불러오는 제목 글꼴은 라틴 문자 2개 합계 46,988바이트로 약 99% 줄었습니다. 한글은 해당 문자가 사용될 때 불러오며, 향후 문구 변경을 위해 완성형 11,172자를 모두 포함합니다. 이 수치는 제목용 글꼴 파일 크기이며 페이지 전체 전송량이나 실측 속도 점수는 아닙니다.
- 원본과 라이선스는 `assets/fonts/source/`에 보관합니다. 파생 글꼴의 내부 이름은 라이선스의 예약 이름 조건에 따라 `ARU Display Latin` / `ARU Display Korean`으로 바꿨습니다. `python3 scripts/build-webfonts.py`로 재생성할 수 있고, 실행에는 fontTools와 Brotli가 필요합니다.
- 메인·왕십리 지점의 검색 제목과 설명을 4개 언어로 정리했습니다. 더블·트윈 객실은 확인된 면적·침대·정원·시설을 반영해 서로 다른 설명을 사용합니다. Open Graph 언어 코드는 지역을 포함하고, 공유 사진은 기존 JPEG 원본을 사용합니다. 화면에서는 AVIF를 유지합니다.
- 예시 후기는 `data-nosnippet` 영역에 넣었습니다. 사이트맵은 실제 수정 이력과 관계없는 빌드 시각을 수정일로 표시하지 않습니다. 초안의 noindex와 사이트맵 제외를 유지합니다.
- 메인 화면의 실제 지점 사진·운영자 사진·객실 사진에 1.3초 동안 선명해지는 효과를 적용했습니다. 화면 높이의 8%(최대 56px) 안쪽에 진입하면 시작하며 사진 위치는 움직이지 않습니다. 첫 화면에 이미 보이는 내용과 키보드로 초점을 받은 내용은 즉시 표시합니다. 자바스크립트가 없어도 본문은 보이며, 움직임 줄이기 설정에는 애니메이션을 적용하지 않습니다. 텍스트 링크에는 밑줄 강조와 작은 화살표 이동을 추가했습니다.
- 최종 프로덕션 빌드·타입 검사·공백 검사가 통과했습니다. 로컬 HTTP 검사에서 48개 페이지의 언어·제목·설명·canonical·hreflang·공유 정보·초안 상태, 16개 사이트맵 URL, 공유 이미지 5개, 제목 글꼴 응답과 잘못된 경로 3개의 404를 확인했습니다.
- 실제 브라우저에서 4개 언어 × 6개 폭(320/390/768/1024/1280/1440px)의 가로 넘침·제목 이탈·헤더 겹침이 없었습니다. 영어·일본어 더블룸도 320/1280px에서 확인했습니다. 스크롤 진입 시 효과 상태와 1회 실행 설정, 모바일 메인 사진 로딩, 예약 팝업의 Escape 닫기와 포커스 복귀를 확인했습니다. 움직임 줄이기는 코드·CSS 조건으로 확인했으며 실제 OS 설정 전환이나 운영 사이트의 검색 색인·Core Web Vitals를 측정한 결과는 아닙니다.
- 커밋·푸시·배포는 아직 실행하지 않았습니다. 실제 예약 URL 연결과 초안 콘텐츠 교체는 남아 있습니다.

- 메인 사진 로딩이 완료되면 2.2초 동안 1.045배에서 원래 크기로 돌아옵니다. 로딩 전에도 같은 시작 배율을 적용해 애니메이션 시작 순간의 크기 변화를 방지합니다. 사진의 영역을 고정하고 안에서만 확대해 레이아웃이나 모바일 본문을 밀지 않습니다.
- 첫 화면의 브랜드 문구·제목·설명·링크는 한 덩어리로 1.6초 동안 22px 올라옵니다. 불투명도는 0.55에서 1로 변하고 개별 문구의 시간차는 없습니다. 사진·문구·스크롤 효과 모두 `cubic-bezier(0.33, 0, 0.67, 1)`로 천천히 시작하고 멈춥니다. 예약 혜택 패널은 고정합니다. 모두 1회만 실행하며 움직임 줄이기 환경에서는 적용하지 않습니다.
