## 예약 바 수정 · 2026-10-26

사용자가 붙여준 기획 내용이 전체 요구사항임을 확인. 하단 상시 고정은 필수 요건이 아니며, 사용자 승인한 제안대로 조정.
- 공통 레이아웃의 고정 CTA 제거: 홈·지점·정책 페이지에 렌더링하지 않음.
- 객실 상세에만 조건부 예약 바 배치. 본문 예약 패널이 헤더 위로 지나가고 마지막 예약 영역이 아직 화면에 들어오지 않은 동안 표시. 마지막 예약 영역 및 푸터에서는 숨김.
- 객실명 + 예약 버튼 + 공식 예약 정오 체크아웃 혜택. 숨길 때 `hidden`으로 키보드·접근성 트리에서도 제외. 원래 본문 예약 패널과 마지막 예약 영역은 유지.
- 상시 고정 버튼용 전역 하단 80px 여백 제거. 1280px 이상에서는 기존대로 헤더 예약 버튼 사용.
- 린트 및 최종 빌드(타입 검사 포함) 통과.
- 브라우저: 홈·지점 고정 CTA 0개, 상세 첫 화면 숨김, 320×568에서 본문 통과 시 표시 및 마지막 예약 영역 진입 시 숨김, 푸터 숨김 확인. 예약 팝업과 Escape 닫기 후 포커스 복귀 확인.
- 영문·일문 패밀리룸 예약 바 렌더 검사에서 가로 넘침·텍스트 잘림·12px 미만 글자·24px 미만 타깃 탐지 없음. 실제 휴대폰 검증은 별도.
